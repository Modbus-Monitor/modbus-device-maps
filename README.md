# Modbus Device Maps

A public, machine-readable catalog of **101 Modbus device-map previews** for power meters, solar inverters, UPS systems, relays, and industrial equipment.

Each JSON file contains a useful preview of commonly requested registers. The complete maps, direct import, live polling, dashboards, logging, and export are available in [Modbus Monitor XPF](https://www.modbusmonitor.com/download?utm_source=github&utm_medium=referral&utm_campaign=device_maps&utm_content=readme).

## Using a preview

```python
import json
from pathlib import Path

device = json.loads(Path("maps/siemens/sentron-pac-2200.json").read_text())
for register in device["registers"]:
    print(register["display_address"], register["name"])
```

> **Addressing warning:** The preview preserves the published display address. Modbus reference numbers and zero-based protocol offsets vary. Verify the device documentation before polling or writing.

## Repository scope

- Public files are intentionally limited previews, not complete device manuals or complete XPF maps.
- Manufacturer documents, spreadsheets, and internal conversion files are not redistributed.
- The JSON format is validated against [`schemas/modbus-map.schema.json`](schemas/modbus-map.schema.json).
- Corrections and map requests are welcome through GitHub Issues.

## Regenerating

Catalog files are generated by an internal publishing pipeline. External contributors can run `python scripts/validate_catalog.py` for a dependency-free validation pass.
