# Modbus Device Maps

A public, machine-readable catalog of **258 Modbus device-map previews** from the official Modbus Monitor XPF map library.

Each JSON file contains 6-12 representative, read-oriented signals. Complete maps, direct import, live polling, dashboards, logging, and export are available in [Modbus Monitor XPF](https://www.modbusmonitor.com/download?utm_source=github&utm_medium=referral&utm_campaign=device_maps&utm_content=readme).

## Repository scope

- Public files are intentionally limited 6-12 signal previews, not complete device manuals or complete XPF maps.
- Maps marked **Guide upcoming** have a public preview but no linked documentation page yet.
- Manufacturer documents, spreadsheets, source CSV files, and internal conversion files are not redistributed.
- The JSON format is validated against [`schemas/modbus-map.schema.json`](schemas/modbus-map.schema.json).
- Corrections and map requests are welcome through GitHub Issues.

## Regenerating

Catalog files are generated by a private publishing pipeline. External contributors can run `python scripts/validate_catalog.py` for a dependency-free validation pass.
